# Tiered Payout Optimizer

A small SQL + Python project that back-tests weekly delivery-partner incentive
tiers against historical trip logs and flags payout edge cases.

> **Note on data:** all data is **synthetic**, generated by `generate_data.py`.
> This is an independent demo of the technique. It contains no employer data,
> and the numbers it prints are illustrative only.

## What it does
1. Generates synthetic trip records (distance, base payout, paid payout).
2. Flags edge cases with SQL: payouts above the rule, and zero-distance trips that were paid.
3. Aggregates weekly trips per partner and compares candidate incentive tier structures by total cost.

## Run it
Requires Python 3.9+ (standard library only).

```bash
python generate_data.py 20000
python backtest.py
```
Results are printed and saved to `output/backtest_summary.csv`.

## Structure
```
generate_data.py      synthetic data + injected anomalies
backtest.py           tier back-test
sql/schema.sql        table + index
sql/anomalies.sql     edge-case detection
sql/weekly_partner.sql weekly aggregation
```

## Skills shown
SQL (aggregation, CASE), Python, incentive-structure modelling, data validation.
